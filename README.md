# Dota 2 FunPay Lot Bot

Скрипт генерирует красиво оформленные лоты с эмодзи для FunPay по Dota 2 — по одному лоту на каждую ветку.

## Что делает

- Создаёт набор лотов по веткам:
  - Поднятие MMR
  - Калибровка
  - Порядочность
  - Ролевой рейтинг
  - Обучение
- Экспортирует результат в:
  - `output/funpay_dota_lots.csv`
  - `output/funpay_dota_lots.txt`

## Запуск

```bash
python3 bot.py
```

Можно задать свои пути:

```bash
python3 bot.py --csv my_lots.csv --txt my_lots.txt
```

## Примечание

Описание генерируется в HTML-совместимом формате (`<b>...</b>`), что удобно для многих площадок и шаблонов публикации.
