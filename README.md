# Dota 2 FunPay Lot Bot

Скрипт генерирует лоты для FunPay по Dota 2 и может запускаться в режиме интерактивной консоли для полуавтоматического редактирования лотов через браузер.

## Что умеет

- Создаёт набор лотов по веткам:
  - Поднятие MMR
  - Калибровка
  - Порядочность
  - Ролевой рейтинг
  - Обучение
- Экспортирует результат в:
  - `output/funpay_dota_lots.csv`
  - `output/funpay_dota_lots.txt`
- Поддерживает режим `console`:
  - создаёт JSON-конфиг с `golden_key`
  - запрашивает `golden_key` перед авторедактированием
  - открывает страницу лотов на FunPay через Playwright
  - заполняет заголовок и описание в карточках лотов

## Запуск

### 1) Только генерация файлов

```bash
python3 bot.py --mode generate
```

С путями на выбор:

```bash
python3 bot.py --mode generate --csv my_lots.csv --txt my_lots.txt
```

### 2) Интерактивная консоль

```bash
python3 bot.py --mode console
```

При первом запуске создастся конфиг:

`output/funpay_automation_config.json`

Заполните в нём `golden_key` и при необходимости поправьте `selectors` (если FunPay изменит верстку).

## Автоматизация через браузер

Для режима редактирования лотов нужен Playwright:

```bash
pip install playwright
playwright install
```

Важно: скрипт не обходит авторизацию. Если вы не вошли в аккаунт, войдите вручную в открытом окне браузера.
